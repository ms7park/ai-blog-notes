# 💬 블로그 작성 즉시 활용 실전 프롬프트 라이브러리

AI(Gemini, ChatGPT, Claude) 창에 그대로 복사해서 쓸 수 있는 실전 프롬프트 템플릿입니다.  
괄호 `[ ]` 안의 내용만 내 상황에 맞게 바꾸어 입력하세요.

---

## 1. 클릭률(CTR) 3배 높이는 제목 생성 프롬프트

```markdown
당신은 10년 차 디지털 마케팅 카피라이터이자 블로그 전문가입니다.

[주제: 예 - 50대 골프 비거리 늘리기]
[핵심 키워드: 예 - 50대 골프 스윙, 비거리 늘리는 법]
[타겟 독자: 예 - 50~60대 아마추어 골퍼]

위 주제로 독자의 시선을 사로잡고 클릭률을 극대화할 수 있는 블로그 제목 10개를 작성해 줘.
다음 4가지 유형을 골고루 섞어줘:
1. 숫자/손실 회피형 (예: "모르면 500만 원 손해 보는...")
2. 질문/공감형 (예: "아직도 힘으로만 치시나요?")
3. 경험/실제 후기형 (예: "제가 3달 만에 20m 늘린 비결")
4. 초간단 해결책형 (예: "딱 1가지만 바꿨더니...")

*주의: 낚시성 제목은 피하고, 핵심 키워드가 가능한 앞쪽에 배치되게 해줘.*
```

## 2. 첫 3초 만에 독자를 사로잡는 도입부(후킹) 프롬프트

```markdown
블로그 글의 도입부(첫인사 및 본론 직전까지 약 300~400자)를 작성해 줘.

- 주제: [예 - 은퇴 후 건강보험료 지역가입자 전환 시 줄이는 법]
- 타겟 독자의 고통(Pain Point): [예 - 직장 다닐 땐 몰랐는데 퇴직 후 건보료 고지서 받고 깜짝 놀람]
- 필자의 페르소나: [예 - 작년에 정년퇴직한 60대 초반 선배 블로거]

[도입부 작성 원칙]:
1. 딱딱한 첫인사("안녕하세요~ 오늘은...")는 생략하고, 공감 가는 상황 질문으로 시작할 것.
2. 필자의 실제 고민과 당황스러웠던 감정을 짧게 공유할 것.
3. "이 글을 끝까지 읽으시면 딱 2가지 서류로 월 10만 원 이상 아끼는 비결을 알게 됩니다"처럼 명확한 독자 혜택을 제시할 것.
4. 문장은 2~3줄씩 짧게 끊어서 모바일에서 읽기 편하게 해줘.
```

## 3. 구조화된 본문(소제목별) 작성 프롬프트

```markdown
블로그 본문 중 소제목 하나를 작성하려고 해.

- 소제목: [예 - 국민연금 연기연금 vs 조기연금, 나에게 유리한 선택은?]
- 포함할 내용: [신청 나이, 감액/증액 비율, 손익분기점 나이, 상황별 추천]
- 문체: 친절하고 신뢰감 있는 경어체 (~해요, ~합니다)

[요구사항]:
1. 복잡한 규정을 누구나 이해하기 쉽게 실생활 예시로 풀어줘.
2. 한눈에 비교할 수 있는 표(Markdown Table)를 1개 포함해 줘.
3. 중요한 핵심 문장은 굵은 글씨(Bold)나 불릿 기호(▪)로 시각화해 줘.
4. "~에 대해 알아보았습니다" 같은 지루한 문구는 쓰지 말아줘.
```

## 4. 'AI 냄새' 없애고 감성을 불어넣는 윤문 프롬프트

```markdown
아래 글은 AI가 작성한 초안이야. 기계적인 느낌이 나지 않도록 자연스러운 사람의 문체로 리라이팅(윤문)해 줘.

[내가 실제로 겪은 경험 메모]:
[예 - "지난주에 친구들이랑 파3 골프장에 갔는데, 60m 어프로치에서 계속 뒤땅이 나서 망신당함. 프로한테 원포인트 레슨 받고 체중을 왼발에 두는 법을 배움."]

[수정할 원문 초안]:
"""
(여기에 AI가 쓴 초안 붙여넣기)
"""

[윤문 지침]:
1. 위 '내가 겪은 경험 메모'를 글의 중간에 자연스럽게 1인칭 관점으로 녹여줘.
2. "현대 사회에서", "중요한 요소로 작용합니다", "결론적으로" 등 진부한 상투어를 전부 삭제해 줘.
3. 동네 이웃이나 후배에게 편안하게 커피 한잔 마시며 이야기해 주듯 구어체 느낌을 살려줘.
```

## 5. 댓글/공감 및 수익 링크 클릭을 부르는 마무리(CTA) 프롬프트

```markdown
블로그 글의 마무리(결론) 3~4문장을 작성해 줘.

- 주제: [예 - 가성비 시니어 골프 거리측정기 추천]
- 유도할 행동(CTA): [예 - 독자의 댓글 의견 묻기 + 본문 속 할인 링크 확인 유도]

[작성 원칙]:
1. 오늘 핵심 내용을 딱 3줄로 요약해 줘.
2. 독자에게 질문을 던져 댓글을 유도해 줘 (예: "선배님들은 라운드 때 어떤 장비 쓰시나요? 댓글로 알려주세요!")
3. 자연스럽게 정보나 링크를 다시 한번 상기시켜 줘.
```
