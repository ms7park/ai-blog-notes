# Article Production Process (초안 생성 · 검증 · 편집 표준 절차)

## 1. '주제 조사 1회 → 플랫폼별 원고 2편' 생산 원칙

작업 피로도를 줄이면서 두 블로그의 품질을 동시에 유지하기 위해 **자료 조사는 한 번에 수행하되, 원고 작성은 플랫폼 문법에 맞게 완전히 분리**합니다.

```
[공통 1단계: 공식 자료 조사 및 팩트 확인 (5분)]
        ├── 🟢 [네이버 초안 생성] : 도입부 공감 + 핵심 3대 포인트 + 인생 2막 통찰 + 스마트블록 태그
        └── 🟠 [티스토리 초안 생성] : 결론 선제시 + 단계별 절차(1~4단계) + 조건별 비교표 + 공식 URL + 주의사항
```

---

## 2. 단계별 원고 제작 프로세스

### Step 1. 공식 자료 수집 및 팩트 시트 작성 (5분)
초안을 생성하기 전 아래 4가지를 먼저 메모합니다.
1. **공식 출처 URL**: 공단, 정부 부처, 한국은행, 한국거래소, 공식 제조사 고객센터 URL
2. **핵심 수치·조건**: 기준 연도(2026년), 대상 연령, 소득 기준, 수수료율/세율, 신청 기간
3. **절차 순서**: 실제 사이트 접속 경로 (`홈페이지 → 메뉴명 → 인증 → 결과 확인`)
4. **예외 및 주의사항**: 감액 조건, 제외 대상, 개인별 차이 발생 요인

### Step 2. 플랫폼별 AI 초안 생성 (10분)
- **네이버용 원고**: `prompts/naver-draft.md` 프롬프트 사용
  - 친근하고 신뢰감 있는 '품미인생' 페르소나 유지
  - 모바일 가독성을 위한 짧은 문단, 인용구, 핵심 요약 리스트 활용
- **티스토리용 원고**: `prompts/tistory-draft.md` 프롬프트 사용
  - 객관적이고 정확한 정보 편집자 톤앤매너 유지
  - **7단계 표준 구조**: `1. 도입부 → 2. 핵심 내용 요약 → 3. 단계별 설명 → 4. 사례 또는 비교표 → 5. 주의사항 → 6. 결론 → 7. 참고 자료`

### Step 3. 사실 검증 및 휴먼 터치 편집 (7분)
AI가 생성한 초안에서 아래 항목을 반드시 수정·편집합니다.
1. **할루시네이션(허위 수치) 교정**: 공식 자료에서 확인되지 않은 숫자·통계·가격은 삭제하거나 공식 확인 경로로 대체합니다.
2. **가상 경험담 제거**: 직접 겪지 않은 일을 *"제가 어제 직접 신청해 보니..."*처럼 서술한 문장을 객관적 절차 설명으로 수정합니다.
3. **비교표 가정 조건 명시**: 모든 계산 사례와 비교표 하단에 기준 연도와 가정 조건을 명시합니다.
4. **문장 중복 제거**: 상투적인 AI 서론(*"급변하는 현대 사회에서..."*)을 걷어내고 첫 문단부터 독자의 질문에 바로 답합니다.
