# Fact-Check & Quality Verification Prompt (초안 사실 검증 프롬프트)

## 1. 프롬프트 목적
AI가 작성한 네이버·티스토리 블로그 초안을 발행하기 전, 할루시네이션(사실 오류), 가상 경험담, 과장된 제목, 정책 위반 요소를 검출하고 교정하는 프롬프트입니다.

---

## 2. 복사해서 바로 쓰는 프롬프트

```markdown
당신은 엄격한 팩트체커이자 웹 출판 에디터입니다.
아래 블로그 초안을 검토하여 발행 전 수정해야 할 항목을 찾아내고 교정본을 제시해 주세요.

## 검토 대상 원고
[검토할 초안 붙여넣기]

## 참고한 공식 출처
[공식 사이트 URL 및 기준 수치]

## 필수 점검 기준
1. [수치·법령 검증]: 본문 내 연도, 날짜, 세율, 수수료, 지원금, 연령 기준이 공식 자료와 일치하는가? 확인되지 않은 숫자가 있다면 지적하고 안전한 표현으로 수정하세요.
2. [제목-본문 일치]: 제목에서 약속한 질문의 답이 도입부와 본문에 명확히 들어 있는가? 과장되거나 낚시성 표현이 있다면 수정하세요.
3. [가상 경험 배제]: 직접 겪지 않은 일을 1인칭 실제 경험처럼 지어낸 문장이 있는가? 있다면 객관적인 절차 안내 문장으로 교정하세요.
4. [가정 조건 명시]: 계산 사례나 비교표에 기준 연도(2026년)와 가정 조건, 개인별 차이 유의사항이 명시되어 있는가?
5. [중복 및 상투어 제거]: 불필요하게 반복되는 서론이나 키워드 나열을 삭제하세요.

## 출력 형식
1. 발견된 수정 필요 항목 (위험도: 높음/보통/낮음)
2. 공식 자료 추가 확인이 필요한 문장 목록
3. 팩트체크가 반영된 최종 교정 원고
```
