# 📝 블로그 아이디어 & 영감 메모장 (Idea Scratchpad)

일상 속에서 떠오르는 아이디어, 나누고 싶은 경험, 뉴스 기사를 보며 든 생각을 자유롭게 적어두는 공간입니다.  
적어둔 메모를 복사해서 AI에게 **"이 메모를 바탕으로 블로그 글 초안을 써줘"**라고 요청하면 됩니다.
