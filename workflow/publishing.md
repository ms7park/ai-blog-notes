# Publishing Checklist (발행 전 최종 점검 및 기록 절차)

## 1. 발행 전 필수 3대 핵심 질문

모든 글은 발행 버튼을 누르기 전에 아래 세 가지를 통과해야 합니다.

1. **[사실 일치]** 공식 자료와 본문 내 숫자·날짜·조건이 정확히 일치하는가?
2. **[제목 일치]** 제목이 본문에서 실제로 답하는 핵심 질문과 과장 없이 일치하는가?
3. **[경험 진실성]** 직접 해보지 않은 일을 본인의 실제 경험처럼 허위로 표현하지 않았는가?

---

## 2. 플랫폼별 발행 전 점검 체크리스트

### 🟢 네이버 블로그 (`blog.naver.com/ms7park`) 발행 체크리스트
- [ ] 포스트 뷰어(`.html`)에서 **[🟢 네이버 스마트에디터 서식 복사]** 버튼을 사용해 `**` 기호 없이 깔끔하게 붙여넣었는가?
- [ ] 제목 앞쪽 15자 이내에 핵심 타겟 키워드가 자연스럽게 배치되었는가?
- [ ] 본문 소제목(인용구/구분선)이 3~4개로 명확히 나뉘어 있는가?
- [ ] 저작권 문제가 없는 이미지(직접 촬영 사진, 공식 화면 캡처, 무료 라이선스)를 사용했는가?
- [ ] 하단 해시태그에 `#은퇴블로그` 대신 `#인생2막`, `#품미인생`, `#디지털연금` 및 주제 키워드가 들어갔는가?
- [ ] 공개 설정이 **전체 공개**로 되어 있는가?

### 🟠 티스토리 블로그 (`똑똑한 생활탐구`) 발행 체크리스트
- [ ] 포스트 뷰어(`.html`)에서 **[🟠 티스토리 에디터(기본모드) 서식 복사]** 또는 마크다운 원문으로 표·소제목이 깨짐 없이 입력되었는가?
- [ ] 5대 카테고리(`은퇴·연금·생활비`, `AI·IT 활용법`, `제품 비교·사용법`, `골프·취미`, `반려동물·생활정보`) 중 정확한 카테고리를 선택했는가?
- [ ] 도입부 상단에 **핵심 답변 요약 박스**가 배치되어 있는가?
- [ ] 본문 내 **조건별 비교표(Table)**가 모바일 미리보기에서도 가로 잘림 없이 잘 보이는가?
- [ ] 하단 **참고 자료** 섹션의 공식 기관 외부 링크가 새 창에서 정상적으로 열리는가?
- [ ] 네이버 블로그에 올린 원고와 문장·구성이 중복되지 않는 독창적인 글인가?

---

## 3. 발행 직후 기록 절차 (`Step 8`)

1. 발행된 실제 게시글을 브라우저에서 열어 링크와 이미지를 최종 확인합니다.
2. `logs/publishing-log.csv` 파일에 오늘 발행한 글의 `날짜, 플랫폼, 카테고리, 주제, 제목, URL, 상태(published)`를 한 줄 추가합니다.
3. 티스토리 글의 경우 Google Search Console에서 색인 생성 현황을 주기적으로 점검합니다.
